This project for automation testing using playwright for CURA Health Service.
This project still need improve for any module but for this time I wanna share for 3 module, that is Login, Logout and Make Appoinment. Pengujian ini mengadopsi pendekatan *Data-Driven Testing* menggunakan file input CSV serta pola desain *Page Object Model (POM)*.


Tools :
1. Node.js
2. Vscode (Text Editor)
3. Playwright (framework)
4. Javascript (language)

Step by steps:
1. Install node.js
2. Install vscode
3. Clone repository
4. Git init
Install playwright -> npm init playwright@latest
